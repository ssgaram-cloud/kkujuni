# 꾸준이 — 세무사 1차 공부관리툴 PRD

Oct 14, 2026 · @장순조

## 1. 개요

세무사 1차 4개 과목의 공부시간을 과목×유형별로 START/STOP 기록하고, 통계·오답노트를 구글드라이브로 PC·모바일 간 동기화하는 1인용 웹앱이다. 사용 시나리오는 범위에서 제외하고 기능 요구사항만 정의한다.

- **사용자**: 본인 1인 (다중 사용자·공유 기능 없음)
- **플랫폼**: PWA(Progressive Web App) 단일 코드베이스 — PC 브라우저, 모바일 홈화면 설치 겸용
- **저장 구조**: 기기 로컬(IndexedDB) 우선 저장 → 본인 구글드라이브로 동기화. 별도 서버 없음
- **언어**: 한국어 UI만 제공

### 1.1 과목 (고정 4개)

| 코드 | 과목 | 비고 |
| --- | --- | --- |
| FIN | 재정학 | 필수 |
| TAX | 세법학개론 | 필수 |
| ACC | 회계학개론 | 필수 |
| COM | 상법 | 선택과목 |

영어는 공인영어성적 대체 과목이므로 제외한다.

### 1.2 공부 유형 (고정 5개)

| 코드 | 유형 |
| --- | --- |
| LEC | 강의 |
| TXT | 기본서 |
| PRB | 문제풀이 |
| WRG | 오답복습 |
| MOC | 모의고사 |

모든 공부 기록은 과목 1개 + 유형 1개의 조합으로 저장한다.

## 2. F1 공부기록 (START/STOP)

홈 화면에 과목별 카드 4개를 두고, 각 카드에서 유형을 고른 뒤 START로 세션을 시작한다. 동시에 진행되는 세션은 항상 1개다.

| ID | 요구사항 | 우선순위 |
| --- | --- | --- |
| F1-01 | 과목 카드 4개(재정학·세법학개론·회계학개론·상법)를 홈 화면에 2×2(모바일) / 4열(PC)로 표시 | P0 |
| F1-02 | 각 카드에 유형 선택 칩 5개(강의·기본서·문제풀이·오답복습·모의고사). 직전에 쓴 유형을 기본 선택 | P0 |
| F1-03 | 카드별 START 버튼: 누르면 세션 생성(startAt = 현재 시각), 카드가 '진행 중' 상태로 강조 | P0 |
| F1-04 | 진행 중 카드의 버튼은 STOP으로 전환. 누르면 endAt 기록, 타이머 정지 후 진도 메모 시트(F1-13) 표시 → '저장하고 종료' 시 세션 확정 | P0 |
| F1-05 | 다른 과목 START 시 진행 중 세션을 자동 STOP 후 새 세션 시작 (확인 토스트 표시) | P0 |
| F1-06 | PAUSE/CONTINUE: 하단 타이머 바의 PAUSE로 일시정지, CONTINUE로 재개(F2-04). 정지 구간은 pauses\[\]에 저장하고 순공부시간에서 제외 | P0 |
| F1-07 | 1분 미만 세션은 저장하지 않고 '기록 취소' 토스트 표시 (기준값 설정에서 변경 가능) | P1 |
| F1-08 | STOP 시 진도 메모 입력 (상세는 2.1 진도 메모 시트) | P0 |
| F1-09 | 각 카드에 오늘 누적시간 표시 (예: 오늘 2:35) | P0 |
| F1-10 | 앱 종료·새로고침·기기 잠금 후에도 세션 유지: 경과시간은 startAt 기준으로 재계산 | P0 |
| F1-11 | 자정을 넘긴 세션은 통계 집계 시 날짜별로 분할 (저장은 1건 유지) | P0 |
| F1-12 | 진행 중 상태로 12시간 경과 시 '종료 누락' 배지 표시 → 종료시각 직접 입력 유도 | P1 |
| F1-13 | 홈 '오늘 기록' 목록에 세션별 진도 범위·메모를 함께 표시 | P0 |

### 2.1 STOP 진도 메모 시트

STOP을 누르면 타이머가 즉시 멈추고(종료시각 확정), 화면 하단에서 진도 메모 시트가 올라온다. 카드의 STOP과 하단 타이머 바의 STOP 모두 같은 시트를 연다.

| ID | 구성 요소 | 내용 | 우선순위 |
| --- | --- | --- | --- |
| F1-14 | 세션 요약 | 과목·유형 칩, 순공부시간(HH:MM:SS), 시간대(시작–종료), 일시정지 합계(분) | P0 |
| F1-15 | 지난 진도 | 같은 과목의 직전 진도 범위를 참고용으로 표시 (없으면 '이전 진도 기록 없음') | P0 |
| F1-16 | 진도 범위 입력 | 한 줄 입력. 예: 기본서 p.120–158 / 인강 15강 | P0 |
| F1-17 | 메모 입력 | 여러 줄 입력. 예: 3장 리스 끝, 리스변경 회계처리 다시 볼 것 | P0 |
| F1-18 | 풀이 결과 | 유형이 문제풀이·모의고사일 때만 '풀이 문항수 / 정답수' 숫자 입력 표시 | P1 |
| F1-19 | 계속 공부하기 | 시트를 닫고 세션 재개. STOP 전에 PAUSE 상태였다면 일시정지 상태로 복귀 | P0 |
| F1-20 | 저장하고 종료 | 세션 확정 저장, 입력값이 비어 있어도 저장 가능 | P0 |
| F1-21 | 사후 수정 | 진도·메모는 기록 관리(F3-02)에서 나중에 수정 가능 | P0 |

- 시트가 열린 동안에는 뒤 화면 조작을 막고, 앱 종료 시 입력 중인 내용은 로컬에 임시 저장한다.
- 다른 과목 START로 자동 종료(F1-05)된 세션은 시트 없이 저장하고 메모에 '자동 종료'를 남긴다.

세션이 진행 중이면 화면 하단에 고정 바가 나타나 경과시간이 1초 단위로 흐른다. 어느 탭(기록·진도·통계·오답노트·설정)에 있어도 항상 보인다.

| ID | 요구사항 | 우선순위 |
| --- | --- | --- |
| F2-01 | 하단 고정(sticky) 바 2단 구성: 윗줄 = 과목명 · 유형 · 시작시각 · 경과시간(HH:MM:SS), 아랫줄 = PAUSE(또는 CONTINUE) · STOP 버튼 (각 높이 48px 이상) | P0 |
| F2-02 | 과목별 고유 색상으로 바 배경 표시 (재정학/세법/회계/상법 4색) | P0 |
| F2-03 | 경과시간 = 현재시각 − startAt − 일시정지 합계. setInterval 누적 방식 금지(백그라운드 오차 방지) | P0 |
| F2-04 | PAUSE/CONTINUE 버튼: 진행 중에는 PAUSE, 일시정지 중에는 같은 자리에 CONTINUE 표시(모바일 토글). PC는 PAUSE·CONTINUE를 나란히 두고 비활성 쪽을 흐리게 표시. 일시정지 중에는 시간이 깜빡이고 '일시정지 중' 라벨 표시 | P0 |
| F2-05 | 바 탭 시 확장: 오늘 해당 과목 누적시간, 이번 세션 시작시각 표시 | P1 |
| F2-06 | 브라우저 탭 제목에 경과시간 표시 (예: ⏱ 01:23:45 세법학개론) | P1 |
| F2-07 | 모바일 하단 탭바 위에 위치, iOS 홈 인디케이터 영역(safe-area) 침범 금지 | P0 |
| F2-08 | 50분 경과 시 휴식 알림(진동·알림) — 간격은 설정에서 변경, 끄기 가능 | P2 |
| F2-09 | 화면 꺼짐 방지(Wake Lock API) 옵션: 모의고사 유형에서 기본 ON | P2 |

## 5. F8 진도 노트

STOP 때 입력한 진도 범위·메모(F1-16·F1-17)를 모아 보는 조회 화면이다. 다음 공부를 시작하기 전에 과목별로 어디까지 했는지 바로 확인하는 것이 목적이다. 모바일은 하단 탭바 두 번째 탭 '진도', PC는 좌측 메뉴 '진도 노트'로 들어간다.

### 5.1 화면 구성

| ID | 요구사항 | 우선순위 |
| --- | --- | --- |
| F8-01 | 과목별 마지막 진도 카드: 4과목을 2×2(모바일) / 4열(PC)로 표시. 카드 = 마지막 진도 범위, 메모, 유형·순시간, 종료 시각(오늘/어제/날짜) | P0 |
| F8-02 | 이어서 START: 카드 버튼으로 해당 과목·직전 유형 세션을 바로 시작하고 홈 타이머 바 표시 | P0 |
| F8-03 | 카드를 탭하면 아래 기록 목록이 그 과목으로 필터됨 (다시 탭하면 전체) | P0 |
| F8-04 | 진도 기록 타임라인: 날짜별 그룹(최신순), 항목 = 과목·유형·시간대·순시간·진도 범위·메모 | P0 |
| F8-05 | 필터: 과목(전체 + 4과목), 유형(전체 + 5유형) | P0 |
| F8-06 | 검색: 진도 범위·메모 텍스트 검색 (예: 리스, p.200) | P1 |
| F8-07 | 진도를 입력하지 않은 세션은 '진도 미입력'으로 회색 표시, 탭하면 진도·메모를 추가 입력 | P1 |
| F8-08 | 항목을 길게 누르면 기록 수정(F3-02)으로 이동 | P1 |

| F8-10 | PC 레이아웃: 왼쪽 마지막 진도 카드, 오른쪽 타임라인 2단 | P1 |
| F8-11 | STOP 메모 시트의 '지난 진도'(F1-15)에서 '전체 보기'로 진도 노트 해당 과목 화면 열기 | P2 |

### 5.2 데이터 규칙

- 별도 저장소 없이 StudySession의 `progress`·`memo`를 조회해 만든다. 동기화(F6)도 세션 데이터를 그대로 따른다.
- 과목별 마지막 진도 = 그 과목에서 `progress`가 비어 있지 않은 세션 중 `endAt`이 가장 늦은 1건.
- 문제풀이·모의고사 세션의 풀이 결과(F1-18)는 메모 앞에 '20문항 중 16정답' 형식으로 붙여 표시한다.
- 자동 종료 세션(F1-05)과 1분 미만 세션(F1-07)은 마지막 진도 계산에서 제외한다.

## 7. F5 오답노트

## 8. F6 구글드라이브 동기화

각 기기는 IndexedDB에 먼저 저장하고, 본인 구글드라이브의 앱 전용 폴더를 공통 저장소로 삼아 레코드 단위로 병합한다. 별도 백엔드 서버 없이 브라우저에서 Google Drive API v3를 직접 호출한다.

### 7.1 인증·저장 위치

| ID | 요구사항 | 우선순위 |
| --- | --- | --- |
| F6-01 | Google Identity Services(OAuth 2.0)로 로그인. 최초 1회 동의 후 토큰 만료 시 자동 재발급 시도, 실패 시 '다시 연결' 배너 | P0 |
| F6-02 | 권한 범위 최소화: `drive.file` (앱이 만든 파일만 접근). 드라이브 내 다른 파일은 읽지 않음 | P0 |
| F6-03 | 드라이브에 `세무사1차_공부관리/` 폴더 생성, 하위 `data/`, `images/` | P0 |
| F6-04 | 데이터 파일 분할: `sessions_YYYY-MM.json`(월별), `wrongnotes.json`, `settings.json`, `active_session.json` | P0 |
| F6-05 | 오답 이미지는 `images/{noteId}_{seq}.webp` 개별 파일로 업로드, 기기별 로컬 캐시 보관 | P0 |

### 7.2 동기화 동작

| ID | 요구사항 | 우선순위 |
| --- | --- | --- |
| F6-06 | 동기화 시점: 앱 실행, 화면 복귀(visibilitychange), 데이터 변경 후 5초 디바운스, 포그라운드 60초 주기, 수동 '지금 동기화' 버튼 | P0 |
| F6-07 | 병합 규칙: 레코드 id 기준, `updatedAt`이 늦은 쪽 채택(LWW). 삭제는 tombstone(`deleted:true`)으로 전파 | P0 |
| F6-08 | 낙관적 잠금: 업로드 직전 파일 `modifiedTime` 비교 → 변경됐으면 재다운로드·재병합 후 업로드 | P0 |
| F6-09 | 진행 중 세션 공유: PC에서 START한 세션이 모바일 하단 타이머에도 흐르고, 어느 기기에서든 STOP 가능 | P0 |
| F6-10 | 두 기기에서 동시에 다른 세션 START 시: 먼저 시작한 세션을 나중 START 시각으로 자동 STOP 후 알림 | P1 |
| F6-11 | 오프라인: 변경분을 로컬 큐에 적재, 연결 복구 시 순차 업로드. 오프라인 중에도 타이머·기록·오답 등록 정상 동작 | P0 |
| F6-12 | 상태 표시: 상단 아이콘으로 동기화됨 / 동기화 중 / 오프라인 / 오류, 마지막 동기화 시각 | P0 |
| F6-13 | 이미지 지연 로딩: 목록은 썸네일만, 상세 진입 시 원본 다운로드 후 캐시 | P1 |
| F6-14 | 전체 백업: 설정에서 전체 데이터 JSON + 이미지 ZIP 내보내기 / 가져오기 | P2 |

### 7.3 동기화 흐름

1. 로컬 변경 발생 → IndexedDB 저장 + `dirty` 표시
2. 동기화 트리거 → 드라이브에서 해당 JSON 다운로드
3. 로컬·원격 레코드를 id별 LWW 병합
4. `modifiedTime` 재확인 후 업로드 (불일치 시 2단계로 복귀)
5. 성공 시 `dirty` 해제, 마지막 동기화 시각 갱신

## 10. 데이터 모델

모든 레코드는 공통 필드 `id`(UUID), `createdAt`, `updatedAt`, `deleted`, `deviceId`를 가지며 시각은 ISO 8601(+09:00)로 저장한다.

### 9.1 StudySession (`sessions_YYYY-MM.json`)

| 필드 | 타입 | 설명 |
| --- | --- | --- |
| subject | enum | FIN / TAX / ACC / COM |
| type | enum | LEC / TXT / PRB / WRG / MOC |
| startAt | datetime | 시작 시각 |
| endAt | datetime \| null | 종료 시각, 진행 중이면 null |
| pauses | \[{from, to}\] | 일시정지 구간 |
| netSeconds | int | 순공부시간(초), STOP 시 확정 |
| source | enum | timer / manual |
| progress | string | 진도 범위 (STOP 시트 F1-16) |
| memo | string | 메모 (STOP 시트 F1-17) |
| solved / correct | int | 문제풀이·모의고사 문항수 / 정답수 (선택) |
| score | number | 모의고사 점수 (선택) |

### 9.2 WrongNote (`wrongnotes.json`)

| 필드 | 타입 | 설명 |
| --- | --- | --- |
| subject | enum | 과목 |
| chapter | string | 단원 |
| sourceRef | string | 교재·회차·문항번호 |
| problemImages | \[fileId\] | 문제 이미지 드라이브 파일 id |
| answerImages | \[fileId\] | 해설 이미지 드라이브 파일 id |
| reasons | \[enum\] | 개념부족 / 계산실수 / 문제오독 / 암기누락 / 시간부족 |
| memo | string | 메모 |
| reviews | \[{at, result}\] | 복습 이력 (result = correct / wrong) |
| status | enum | active / done |
| nextReviewAt | date | 다음 복습 예정일 (F5-09) |

### 9.3 ActiveSession (`active_session.json`)

진행 중 세션 1건의 `sessionId`, `subject`, `type`, `startAt`, `pauses`, `deviceId`만 담는다. STOP 시 비우고, 해당 세션은 월별 파일에 확정 저장한다.

## 12. 릴리스 범위 및 확인 필요 사항

P0 전체를 MVP로 먼저 완성하고, P1·P2는 순차 추가한다.

| 단계 | 포함 범위 | 완료 기준 |
| --- | --- | --- |
| MVP (P0) | 과목 카드·START/STOP, 하단 타이머 바(PAUSE/CONTINUE 포함), STOP 진도 메모 시트, 진도 노트(F8-01~05), 기록 수정·수동 추가, 통계 기본 카드(F4-01\~06), 오답노트 등록·조회·이미지, 드라이브 동기화·오프라인 | PC에서 START → 모바일 타이머 표시 → 모바일에서 STOP → PC 통계 반영까지 정상 동작 |
| 2차 (P1) | 풀이 문항수·정답수 입력, 목표 달성률, 연속일수, 히트맵, D-day, 오답 복습 기록·해설 가리기, 오답복습 세션 연동 | 1주 실사용 후 기록 누락·충돌 0건 |
