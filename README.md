# 꾸준이 — 세무사 1차 공부관리

과목별 공부시간(START · PAUSE · CONTINUE · STOP), STOP 때 진도 메모, 진도 노트, 일·주·월간 통계, 사진 오답노트를 기록하고 **본인 구글드라이브로 PC·휴대폰을 동기화**하는 웹앱(PWA)입니다.

- 과목: 01_재무 · 02_원가 · 03_세법 · 04_재정 · 05_상법 · 06_기타
- 공부 유형: 강의 · 기본서 · 문제풀이 · 오답복습 · 모의고사
- 하나의 코드로 PC 브라우저와 휴대폰(홈 화면에 추가) 모두 사용
- 서버 없음: 데이터는 각 기기(IndexedDB)와 본인 구글드라이브 `꾸준이` 폴더에만 저장

## 1. 바로 실행 (내 PC에서)

```bash
npm install
npm run dev        # http://localhost:5173
```

`npm run build` 하면 `dist/` 폴더에 배포용 파일이 만들어집니다. `npm test`는 시간 계산·통계·동기화 병합 테스트를 돌립니다.

## 2. 인터넷에 올리기 (휴대폰에서도 쓰려면 필수)

구글 로그인과 홈 화면 설치는 **HTTPS 주소**에서만 동작합니다. 무료 방법 두 가지 중 하나를 고르세요.

**GitHub Pages**
1. GitHub에 새 저장소(예: `kkujuni`)를 만들고 이 폴더를 올립니다.
2. 저장소 Settings → Pages → Source를 **GitHub Actions**로 바꿉니다.
3. 포함된 `.github/workflows/deploy.yml`이 자동으로 빌드·배포합니다.
4. 주소: `https://<GitHub아이디>.github.io/kkujuni/`

**Vercel**
1. vercel.com에서 GitHub 저장소를 Import → Framework는 Vite 자동 인식 → Deploy.
2. 주소: `https://<프로젝트명>.vercel.app`

## 3. 구글드라이브 동기화 켜기 (한 번만)

1. https://console.cloud.google.com 에서 새 프로젝트를 만듭니다.
2. **API 및 서비스 → 라이브러리**에서 `Google Drive API`를 검색해 **사용**을 누릅니다.
3. **OAuth 동의 화면**: User Type `외부` → 앱 이름 `꾸준이`, 이메일 입력 → 범위는 건너뜀 → **테스트 사용자에 본인 Gmail 추가**. 게시 상태는 `테스트`로 둡니다(본인만 쓰므로 검수 불필요).
4. **사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**
   - 애플리케이션 유형: `웹 애플리케이션`
   - 승인된 JavaScript 원본: 2단계의 주소 **도메인까지만** (예: `https://아이디.github.io`). 로컬 테스트도 하려면 `http://localhost:5173` 추가
   - 리디렉션 URI는 비워 둡니다.
5. 발급된 클라이언트 ID(`…apps.googleusercontent.com`)를 앱의 **설정 → 구글드라이브 동기화**에 붙여넣고 **구글 계정 연결**을 누릅니다. PC와 휴대폰 모두 같은 계정으로 연결하면 끝입니다.
   - 매번 입력하기 싫으면 빌드 전에 `.env` 파일에 `VITE_GOOGLE_CLIENT_ID=발급받은ID`를 넣어 두세요.

### 동기화 동작
- 앱 실행·화면 복귀·변경 5초 후·1분마다 자동 동기화, 설정에서 `지금 동기화`
- 드라이브 `꾸준이/data/`에 `sessions_YYYY-MM.json`(월별), `wrongnotes.json`, `settings.json`, `active.json`, `꾸준이/images/`에 오답 이미지(WebP)
- 레코드별로 나중에 고친 쪽을 채택하고, 삭제는 삭제표시로 다른 기기에 전파
- PC에서 START한 공부는 휴대폰 하단 타이머에도 보이고 어느 기기에서든 STOP 가능. 두 기기에서 동시에 START하면 먼저 시작한 쪽을 자동 종료
- 오프라인에서도 기록·오답 등록이 되고, 연결되면 올립니다
- 권한은 `drive.file`(앱이 만든 파일만)이라 드라이브의 다른 파일은 읽지 않습니다

### 알아둘 점
- 동의 화면이 `테스트` 상태면 구글 로그인 유지가 짧을 수 있습니다. 동기화 상태가 '다시 연결 필요'로 바뀌면 설정에서 `다시 연결`을 한 번 누르면 됩니다(데이터는 기기에 그대로 있음).
- iPhone은 Safari에서 공유 → **홈 화면에 추가**로 설치하세요. 화면을 끄면 타이머 화면은 멈추지만 시작 시각 기준으로 계산하므로 다시 열면 정확한 시간이 표시됩니다.

## 4. 폴더 구조

```
public/            아이콘(icon.svg, PNG), PWA 리소스
src/lib/           데이터·시간·통계·이미지 압축, google/(인증·드라이브·병합·동기화)
src/components/    타이머 바, STOP 진도 메모 시트, 공통 UI
src/pages/         기록(홈) · 진도 노트 · 통계 · 오답노트 · 기록 관리 · 설정
```
